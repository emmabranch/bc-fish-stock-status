Management context

Text in quotation marks is copied exactly as published in DFO’s 2024 Sustainability Survey for Fisheries, including any typos.

  • Limit reference point, as described by DFO: Not reported
  • Upper stock reference, as described by DFO: Not reported

Data gaps and caveats

  • Not included in DFO’s 2024 Sustainability Survey, so there is no official status zone here.
  • No fishing-pressure ratio relative to MSY, so no Kobe plot.
  • Limit reference point taken or derived from RAM Legacy; DFO’s current value may differ.
