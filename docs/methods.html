Methods and data

Summary

This project combines two open sources into a small, documented database for ten British Columbia stocks. It applies simple written rules to describe each stock’s status, its history, and the gaps in the evidence. It is a learning project by an epidemiologist who is new to fisheries science. It does not replicate DFO’s methods or those of any seafood recommendation program, and it makes no recommendations.

Data sources

Data tiers

Stocks differ in how much public evidence exists. Each stock is assigned a tier, and the tier decides which plots and caveats it gets.

Tier Meaning Stocks
A Biomass and fishing pressure relative to MSY Sablefish, Pacific halibut
B Biomass relative to MSY only Pacific cod (5ABCD)
C Biomass and catch trends, no MSY ratios Five Pacific herring areas
D DFO status zone only, no assessment time series compiled Spot prawn, Dungeness crab

A common indicator

Stocks use different reference points, so they cannot be compared directly. For every stock with a time series, this project divides biomass by that stock’s limit reference point (LRP), the level below which DFO considers serious harm to be occurring. A value below 1 means below the limit. The limits are taken or derived from RAM Legacy and are approximate.

Data dictionary

Downloads

  • stocks.csv: one row per stock
  • timeseries.csv: long-format time series, one row per stock, year, and metric
  • landings.csv: BC commercial landings by species group
  • data_dictionary.csv: every field in every table

How it is built

All steps are R scripts in the GitHub repository, run in order:

  1. 01_download.R: downloads the raw files.
  2. 04_build_database.R: builds the tidy tables and data dictionary.
  3. 05_herring_stripes.R: herring biomass stripes for the Explore page.
  4. 06_harmonise_lrp.R: adds the biomass-to-limit indicator and runs the cross-checks.
  5. 07_make_figures.R and 08_map_cards.R: figures, map, and cards.
  6. 09_render_reports.R: renders one parameterised 2-page PDF per stock.
  7. 10_make_site_files.R and 11_make_banner.R: stock pages, card styles, and the home page banner.
  8. quarto render: builds this website.

Limitations

  • RAM Legacy copies published assessments, so the time series end between 2018 and 2021 and may not match DFO’s latest advice.
  • Limit reference points used for the common indicator are approximate, and some are derived rather than official.
  • Point estimates only. Assessment uncertainty is not shown.
  • Map pins mark general areas, not stock boundaries.
  • National landings data group several BC species together, so they are not used for stock-level conclusions.
  • Spot prawn and Dungeness crab have no compiled time series; their status here relies entirely on DFO’s survey response.
